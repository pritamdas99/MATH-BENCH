# Project Structure

This workspace contains the Bengali math benchmark dataset, model generations, reruns, and final evaluation artifacts.

## Top-Level Folders

- `data/`  
  Benchmark source files and dataset backups.
  - `eqb.xlsx`: source EQB workbook
  - `eqb.json`: EQB dataset in the shared JSON schema
  - `aks_eqb_style.json`, `aks_eqb_style_2.json`, and
    `aks_eqb_style_merged.json`: AKS datasets in the same schema

- `scripts/`  
  Reusable Python and shell scripts for local Hugging Face inference, OpenRouter reruns, final merging, judging, summarization, and report generation.

- `results/eqb/`
  EQB-only model outputs, labels, summaries, and other evaluation artifacts.
  - `final_model_outputs/`: final model generations
  - `manual_labels/` and `manual_summaries/`: earlier evaluation artifacts
  - `research_gpt41/`: paper-facing labels, summaries, difficulty data, and analysis

- `results/aks/`
  AKS-only model outputs, labels, summaries, and other evaluation artifacts.
  - `final_model_outputs/`: final generations from all six AKS model runs
  - `manual_labels/` and `manual_summaries/`: optional manual evaluation artifacts
  - `research_gpt41/`: LLM-as-judge labels, summaries, difficulty data, and analysis

- `runs/`  
  Intermediate model runs, reruns, smoke tests, and debugging generations.
  - `gemma/`
  - `local_hf/`
  - `mistral_openrouter/`
  - `qwen_smoke/`

- `reports/eqb/`
  EQB-specific Markdown evaluation and analysis reports. The main paper-facing
  report is `reports/eqb/research_gpt41_evaluation_report.md`.

- `reports/aks/`
  AKS-specific Markdown reports generated by scripts in `scripts/aks/`.

- `scripts/aks/`
  AKS-only generation, judging, summarization, and reporting scripts. Run the
  six model launchers individually, or use `scripts/aks/run_all_models.sh`.

- `RESEARCH_PROJECT.md`
  Shared research project notes at the repository root.

- `notebooks/`  
  Original notebook(s), including the OpenRouter key source used by the scripts.

- `logs/` and `pids/`  
  Historical run logs and PID files.

- `tmp/`  
  Temporary test outputs.

- `cache/`  
  Python bytecode cache moved out of the top-level directory.

- `.agents/`  
  Local credential files. Do not commit or share.

## Main Report

Use this file for the final side-by-side model comparison:

```text
reports/eqb/research_gpt41_evaluation_report.md
```

## Rebuilding The GPT-4.1 Report

From the project root:

```bash
.venv/bin/python scripts/build_research_gpt41_report.py
```

## Rebuilding Final Model Outputs

From the project root:

```bash
.venv/bin/python scripts/build_final_jsonl_files.py
```

## Notes

- The project root is intentionally kept small.
- Run commands from the project root unless a script says otherwise.
- `data/eqb.xlsx` remains the default workbook path in maintained scripts;
  `data/eqb.json` is its JSON equivalent.
- Put all new dataset-specific outputs under `results/eqb/` or `results/aks/`
  and all new dataset-specific reports under `reports/eqb/` or `reports/aks/`.
